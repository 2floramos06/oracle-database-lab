# Oracle Database Lab

Repositorio dedicado al desarrollo y práctica de SQL y PL/SQL utilizando Oracle Database.

## Tecnologías
- Oracle Database
- Oracle SQL Developer
- SQL
- PL/SQL
- Git y GitHub

## Estructura del proyecto

- **sql/**: Definición, manipulación y consulta de datos.
- **plsql/**: Desarrollo de lógica procedural y objetos PL/SQL.
- **database/**: Scripts de configuración del entorno de práctica.

## Objetivos

- Desarrollar consultas SQL claras y eficientes.
- Implementar y administrar objetos de base de datos.
- Aplicar conceptos de programación PL/SQL.
- Mantener código SQL organizado y versionado.

## Ejecución

Los scripts están diseñados para ejecutarse en Oracle Database mediante Oracle SQL Developer.

Ejecutar previamente los scripts de configuración necesarios antes de trabajar con objetos dependientes.
